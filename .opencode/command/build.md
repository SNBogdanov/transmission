Собери Transmission. Цели: $ARGUMENTS

**Перед сборкой обязательно уточни у пользователя:**
1. какие цели собирать — `Windows`, `Linux`, `QNAP` (можно несколько);
2. будет ли отладка и на какой машине. Если да — собери только бинарник для этой машины.

Не начинай сборку, пока не получишь ответы (если они не переданы явно в `$ARGUMENTS`). Затем собери **все выбранные цели текущего этапа за один запуск**, не возвращаясь после первой.

Сборка делится на этапы из-за обязательного commit/push: сначала `Windows`; после
успешной Windows-сборки main-сессия делает commit/push через `git-commit`, и только затем
этот же агент собирает `Linux, QNAP` из запушенного коммита. Агент не коммитит и не пушит
сам; получив Linux/QNAP с незапушенным HEAD, он останавливается и сообщает об этом.
При поднятом VPN не ходи по ssh на локальные хосты.
